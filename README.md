# Exltitems

A plugin created to fulfill the need to execute a command to a player, 
ith only one book containing a command behind it when executed.

Commands

![Image](https://github.com/user-attachments/assets/846efcb0-262d-4d04-b55a-6cf4f4675b22)

- /exli create Name "Command" name
- /exli list
- /exli del
- /exli addperm permission name

Java 21
Version 1.20.6 paper
